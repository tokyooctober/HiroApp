# Hiro-Kids UI design sources

Snapshot of the Hiro-Kids UI Design canvas, one `.dc.html` file per screen, saved 6 Oct 2026.
The live, clickable version is the canvas: https://claude.ai/code/artifact/e20d3fcd-420a-4984-b97a-02ccf461c1a8

These files use a design-canvas runtime (`support.js`), so they do not open on their own in a browser.
Read them as markup for layout, copy, colours and sizes; use the canvas to see them rendered.
Screen-to-requirement mapping and design tokens: see `../hiro-kids-spec.md`, section 3, "UI design reference".
